Welcome to FinanceHub

A savings-plan application management demo built with Angular and Spring Boot.

Explore More

About the demo

Browse administrator-created savings plans, submit an application with supporting proof, and track its review status.

This project does not connect to bank accounts, move money, offer loans or investments, or provide financial advice.

Implemented workflows

Savings plans

View available plan details and choose a plan to apply for.

Applications

Submit an application and supporting image for an administrator to review.

Status and enquiries

Track application decisions and send enquiries about plans.
